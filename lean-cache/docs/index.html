Sobre

O lean-cache é um wrapper CLI para o sistema de build lake do Lean 4. Ele implementa um cache endereçável por conteúdo (CAS) que:

  • Resolve o grafo de imports em ordem topológica
  • Calcula chave de conteúdo: fonte + imports + versão do Lean + flags
  • Pula o lake build quando todos os módulos estão em cache hit
  • Restaura artefatos (.olean, .ilean, .c, .o) diretamente no .lake/build/lib/lean/

Recursos

Compressão zstd/lz4

Arquivos ≥64 KB são comprimidos automaticamente para economizar disco e banda de rede.

Evicção LRU

Comando cache gc remove entradas menos acessadas quando excede a quota de disco.

Cache remoto S3 v4

Assinatura AWS v4 para buckets privados, com validação de integridade SHA-256.

Workers remotos

Load balancing round-robin para execução distribuída de builds.

Snapshots lean --server

Salva e restaura estado de elaboração entre sessões do servidor Lean.

Edição cirúrgica

Cache por declaração individual (def, theorem, lemma) para edições locais rápidas.
