lean-cache

Cache endereçável por conteúdo para acelerar builds do Lean 4 em até 40×. Wrapper ao lake build com compressão, workers remotos, S3 v4 e edição cirúrgica.

40× Speedup máximo
0 deps Externas (std-only)
SHA-256 Puro em Rust
S3 v4 Cache remoto

Começar a usar

$ cargo build --release
$ cp target/release/lean-cache /usr/local/bin/
$ lean-cache init
$ lean-cache build MeuArquivo.lean
Ver no GitHub Saiba mais

📦 Cache Endereçável por Conteúdo

Chave = SHA-256(fonte + imports + versão Lean + flags). Builds idênticos são pulados automaticamente.

🗜️ Compressão zstd/lz4/gzip

Arquivos ≥64 KB são comprimidos automaticamente para economizar disco e banda de rede.

🔄 Workers Remotos

Load balancing round-robin para execução distribuída de builds entre múltiplas máquinas.

☁️ Cache Remoto S3 v4

Assinatura AWS v4 para buckets privados com verificação de integridade SHA-256 após download.

⚡ Snapshots lean --server

Salva e restaura estado de elaboração entre sessões, evitando re-elaboração do zero.

🔪 Edição Cirúrgica

Cache por declaração individual (def, theorem, lemma) para edições locais em arquivos grandes.

Comandos Principais

lean-cache init Inicializa o store (.lean-cache)
lean-cache hash arquivo.lean Calcula chave de conteúdo
lean-cache build arquivo.raiz.lean Build acelerado com cache
lean-cache status Estatísticas do store
lean-cache gc Garbage collection LRU
lean-cache remote-set <url> Configura cache remoto HTTP
lean-cache push <chave> Envia artefatos para o remoto
lean-cache pull <chave> Baixa artefatos do remoto
lean-cache s3-push <chave> Envia para S3 (assinatura v4)
lean-cache s3-pull <chave> Baixa do S3
lean-cache surgical-list arquivo.lean Lista declarações cirúrgicas
